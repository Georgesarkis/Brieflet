## Overview

This system is a microservices-based e-commerce platform that handles user authentication, product catalog management, shopping baskets, order processing, and payment workflows. It consists of multiple API services including identity, basket, catalog, ordering, payment, and webhook services, along with a mobile BFF and web application frontend. Data persistence is managed through PostgreSQL databases for each domain, while Redis and RabbitMQ handle caching and event messaging respectively.

## How they talk

- WebApp communicates with basket-api via gRPC and catalog-api and ordering-api via HTTP.
- Basket-API, Catalog-API, and Ordering-API publish events to RabbitMQ for asynchronous processing.
- Order-Processor and Payment-Processor consume events from RabbitMQ to handle business logic.
- Identity-API provides authentication services to basket-api, ordering-api, webhooks-api, and webapp.
- Mobile BFF routes requests to identity-api, catalog-api, and ordering-api for unified mobile access.
